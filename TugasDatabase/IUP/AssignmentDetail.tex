\begin{deliverablebox}{The assignment consists of four parts}
  \begin{enumerate}
    \itemsep0em
    \item translating constraints and business processes into an ER diagram (\textit{Entity Relationship Diagram}). The proposal must be accompanied by an explanation of the ERD formation process
     \item designing and proposing a relational database schema that conforms to the proposed ERD
     \item If a query is given, proposing a representation of the query in relational algebra expressions
     \item Proposing solutions to the questions in the form of SQL queries. If there is more than one possible query (with different operations or clauses), alternative queries must also be written.
\end{enumerate}  
\end{deliverablebox}
